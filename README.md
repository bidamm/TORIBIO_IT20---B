Sorting Algorithms Activity

Unsa ang buhaton sa program?

Ang program mo-sort og 10 ka number gamit ang Bubble Sort, Selection Sort, ug Insertion Sort. Kada usa naay kaugalingong copy sa original nga array. Unya i-print niya ang original ug ang sorted, gikan sa gamay hangtod dako.

Original: 7, 3, 11, 2, 6, 8, 9, 1, 12, 4
Sorted: 1, 2, 3, 4, 6, 7, 8, 9, 11, 12

Unsaon pag-work sa kada usa

Bubble Sort
I-compare ang duha ka number nga magtapad. Kung sayop ang order, i-swap. Balik-balikon hangtod sorted na tanan.

Selection Sort
Pangitaon ang pinakagamay nga number ug ibutang sa una. Unya pangitaon ang sunod nga pinakagamay, ug ingon-ana hangtod humana.

Insertion Sort
Kuhaon ang number ug isulod sa saktong lugar sa wala nga sorted na. Parehas ra sa pag-arrange og baraha.

Unsay kalainan sa tulo

• Bubble Sort: nag-swap sa duha ka magtapad nga number.
• Selection Sort: nangita sa pinakagamay ug gibutang sa una.
• Insertion Sort: gisulod ang number sa saktong lugar.

Reflection

1. Unsaon sa kada usa pag-arrange sa number? Unsay nakalahi?
Ang Bubble Sort nag-swap, ang Selection Sort nangita sa pinakagamay, ug ang Insertion Sort nagsulod sa number sa saktong lugar. Lahi sila kay lahi ang ilang paagi sa pagbalhin sa number.

2. Unsa ang pinakadali sabton ug i-code?
Bubble Sort. I-swap lang ang duha ka number kung sayop ang order.

3. Kung sorted na ang number, kinsa ang pinakapaspas?
Insertion Sort, kay wala na kay usbon.

4. Unsay mahitabo kung daghan na ang number?
Mohinay ang tulo kay daghan na ang i-compare ug i-swap.

5. Ngano importante nga masabtan ang lainlaing sorting algorithms?
Kay walay usa ka algorithm nga maayo sa tanan, so kailangan nako mahibaw-an kung hain ang sakto gamiton.
